Capstone project for IBM's Data Analyst Professional Course with Coursera
# Data Visualization with Python

Completed as the final project of IBM's Data Analyst Professional Certificate on Coursera, this project simulates a real-world analytics engagement for a global IT and business consulting firm. As a Data Analyst, I analyzed data from multiple sources to identify emerging technology tends, in-demand technical skills, and evolving workforce needs. The project involved data collection, data cleaning, exploratory and statistical analysis, visualization, and insight generation to support data-driven workforce planning, hiring, and future skill development. 

### Task 1

The first task focuses on collecting data on in-demand technology skills from job postings, blogs, and developer surveys using web scraping and APIs. Data from CSV files, Excel spreadsheets, and databases is integrated into a unified dataset for analysis and visualization. 

### Task 2

The second task focuses on preparing the collected data for analysis through data wrangling, including removing duplicates, identifying missing values, and applying appropriate imputation techniques. 

### Task 3

The third task applies statistical analysis and EDA to identify trends programming languages, database technologies, IDEs, and developer demographics, transforming the data into actionable insights on technology and workforce trends. 

### Task 4

The fourth task uses SQL to extract relevant data into Python Data frames. These Data frames are used to create charts, plots, histograms to visualize key trends, distributions and relationships. 

### Task 5

The fifth task uses IBM Cognos and Google Looker Studio to create interactive dashboards that enable data exploration and communicate key findings through intuitive visualizations. 

### Task 6

The final task uses data storytelling to present key insights and trends clearly, effectively communicating findings and supporting data-driven decision-making. 

## Data Description

This project uses Stack Overflow's 2019 Developer Survey, which collected approximately 90,000 responses and was released under the Open Database License (ODbL). A randomized 10% subset is analyzed to identify trends in developer technologies, skills, and demographics through data cleaning, analysis, and visualization. 

Dataset Source: [`Stack Overflow 2019 Developer Survey Results`](https://stackoverflow.blog/2019/04/09/the-2019-stack-overflow-developer-survey-results-are-in/)

Dataset Limitations: Findings from the randomized subset may not fully represent the broader developer population or real-world technology trends.
